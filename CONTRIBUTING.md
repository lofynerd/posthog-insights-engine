# Contributing

Thank you for contributing to PostHog Insights Engine.

## Development Workflow

Every feature follows this process:

1. Architecture
2. Implementation
3. Review
4. Testing
5. Merge

No feature should bypass this workflow.

---

## Branch Strategy

main

Production-ready code.

develop

Integration branch.

feature/*

New features.

fix/*

Bug fixes.

hotfix/*

Production fixes.

---

## Commit Messages

Use Conventional Commits.

Examples:

feat:

fix:

docs:

refactor:

test:

chore:

---

## Pull Requests

Every pull request should:

* Follow the architecture
* Pass tests
* Include documentation updates if required
* Keep changes focused
* Avoid unrelated modifications
